## Configure access

Use `.env` for local development or `/etc/osint/osint.env` in production. `.env.example` lists all settings. Restart API and worker after changing configuration. No source keys are entered in the browser. The settings API exposes no secrets and has no endpoint to edit environment configuration.

`OSINT_MAX_RECORDS` defaults to 1,000. Response bytes default to 8 MiB. Raising a record bound requires measuring disk/write costs and respecting provider terms. FIRMS and OpenSky accept `world` or a regional `west,south,east,north` box; regional boxes must be conventional, non-crossing bounds. The current world responses fit the response cap. Larger future responses can exceed it and will fail visibly; tiled queries with provider transaction accounting would be needed for reliable exhaustive acquisition.

Provider collection sampling and dashboard page selection are separate bounds. OpenSky and FIRMS sample occupied 30-degree cells before filling denser cells. The map initially loads 500 records spread across categories and geographic cells; sidebar counts cover all matching stored records. Counts represent retained observations, including successive aircraft position snapshots, not unique aircraft or the provider's full worldwide record count. `Load more events` extends the displayed selection.

Free OpenRouter inference is preferred by configuration, not promised. The default model is `openrouter/free`; the public model catalogue returned HTTP 200 and reported zero prompt/completion prices during verification. Before each uncached analysis the application checks configured model availability against a catalogue cached for one hour. Account quotas remain separate from the local 40-attempt daily default. A provider key and protected administrator token are required to actually run inference. Free availability and limits can change.

On 10 October 2026, a dedicated dashboard key was issued with a $0 total spending limit and a 30-day expiration (9 November 2026). Key authentication and one minimal free-model completion returned HTTP 200. A subsequent protected application request succeeded with two cited claims and two source references from stored USGS reports; a repeated request used the cache. The free router selected `nvidia/nemotron-3-super-120b-a12b:free`. One earlier response failed structured-output validation and was rejected. This small check verifies live credential use, citation membership and caching; representative grounding evaluation remains outstanding. The key is stored only in the ignored `.env` file. Restart both API and worker after configuration changes.

[ACLED's access-level policy](https://acleddata.com/myacled-faqs) assigns Gmail registrations Open access, which does not include API access; Research and higher levels include API access. An institutional registration or provider-approved permission is required before this collector can receive data. Research access also has a data lag, which can affect the collector's seven-day window.

## Current aviation and advisory rules

OpenSky requests `extended=1` to obtain the declared emitter category. Collection and the dashboard select only classes 4 (Large) and 5 (High Vortex Large) with a valid reported position and ground track, before geographic sampling with a 400-observation cap. Class 6, unknown categories and absent tracks are excluded. Omission counts combine this selection and the cap; they do not mean the provider lacked all those positions. Symbols show the latest loaded observation per ICAO24 and use reported ground track clockwise from north, which can differ from nose heading. Source reference: [OpenSky REST state vectors](https://openskynetwork.github.io/opensky-api/rest.html). The live check returned class 4 observations; class 5 support is covered by isolated tests.

NCSC and OFAC default to Single-source and unknown severity. A single country named in the title is regional context; multiple named countries stay unlocated. A country word does not establish actor attribution or independent corroboration. CISA catalog membership remains Verified under the documented evidence policy, but configured vendor-country centers are regional context, not headquarters or exploitation coordinates. Distributed/unknown vendors remain unlocated. The vendor-country mapping is local configuration rather than live geocoding or provider-supplied incident geography.

`python -m backend.repair_context` previews reprocessing of retained CISA/NCSC/OFAC raw records; `--apply` updates their projections while preserving evidence payloads, original ingestion dates and analyst review precedence. The current repair reprocessed 173 CISA and 20 NCSC reports without rejected records.

## Add an authorized RSS/Atom feed

Set JSON environment arrays. Use an exact public hostname in the additional allowlist. Definitions cannot duplicate built-in source IDs. `kind` is `news`, `public`, or `official`; category must be one of the SRS categories. The current RSS adapter assumes English; do not configure non-English feeds without extending its language metadata and tests.

```dotenv
OSINT_EXTRA_ALLOWED_HOSTS=["feeds.example.org"]
OSINT_EXTRA_RSS=[{"source_id":"authorized_public","name":"Authorized public discussion feed","category":"geopolitical","url":"https://feeds.example.org/public.xml","kind":"public"}]
```

The example hostname is a placeholder, not a working source. Only add feeds for which public access and use are authorized. Without a configured discourse feed, that sentiment category correctly contains zero samples. Headlines and excerpts do not represent national public opinion. Keywords group related wording; this release does not infer semantic narrative clusters or topic-specific stance.

## Maritime JSON contract

Set `OSINT_MARITIME_URL`, `OSINT_EXTRA_ALLOWED_HOSTS` and, if needed, `OSINT_MARITIME_TOKEN`. The endpoint must return an object containing an `observations` array. Each record requires:

| Field                   | Type                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- |
| `mmsi`                  | Vessel identifier, string or integer                                         |
| `latitude`, `longitude` | Finite numeric reported coordinates                                          |
| `observed_at`           | Timezone-qualified ISO 8601 position time                                    |
| `source_url`            | Public HTTP(S) provenance reference without embedded credentials             |
| `name`, `class`         | Optional strings                                                             |
| `published_at`          | Optional timezone-qualified publication time; falls back to observation time |

Historical snapshots are stored as separate observations. There is no interpolation or inferred movement between sightings. An adapter for a specific vendor must map its licensed format to this contract or subclass the common connector. No live maritime data is supplied by default.

## Retention and source terms

Defaults are raw payloads 30 days, normalized events/reports 180 days, aggregates 365 days and AI cache seven days. Source IDs, original URLs and record metadata remain in separate supporting reports after raw payload expiry. Provider revisions replace retained raw payloads; this is not an immutable archive of every revision. Backups can outlive application retention, so align backup retention with licensing and deletion requirements.

Feed terms, authentication, update frequency, local disk limits and provider-specific retention can require shorter retention or disabling an adapter. The current retention settings apply globally; per-provider retention and redistribution enforcement remain production work if the chosen licenses demand them.
