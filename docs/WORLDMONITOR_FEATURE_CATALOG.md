# World Monitor feature catalog for Signal Atlas

Research date: **2026-10-15**. Inventory: **184 domain/workflow entries plus 58 map-registry entries** (overlapping, not additive unique features). Scope: public World Monitor documentation and the official repository at [commit `ffa31628243af9054b7f51418486d5115ab4e6dd`](https://github.com/koala73/worldmonitor/tree/ffa31628243af9054b7f51418486d5115ab4e6dd). This is an inventory of publicly evidenced capabilities and incorporation ideas, not a claim to have exercised every feature, purchased Pro, or verified upstream data accuracy. Private product behavior and unadvertised enterprise capabilities are outside this review.

The source-wide map catalog includes layers from specialized variants and renderer-specific paths. It is larger than the layer list visible in a particular dashboard. A class in the repository demonstrates an implementation surface, not that a running deployment has configured data or exposes it by default.

**Evidence:** `D` = official documentation inspected; `S` = pinned source inspected. None of the domain rows below is labelled live-tested. Each row links to its primary evidence. The separate [incorporation plan](WORLDMONITOR_INCORPORATION_PLAN.md) covers live interface observations, accounts, personalization, AI, integrations, source licensing and implementation sequencing.

**Signal Atlas:** `Partial` means a related capability exists, with a material gap; `Existing` means the core capability is already represented; `New` means absent from the documented product baseline. These are implementation assessments from the current [README](../README.md), not claims of equivalent coverage. **Priority:** `P1` = useful near-term addition for the current analyst product; `P2` = later domain expansion; `P3` = specialized or speculative. Priorities are recommendations, not World Monitor claims. Access notes identify explicitly documented restrictions only; provider and API entitlements still require a separate check.
